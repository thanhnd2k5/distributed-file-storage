# Repository instructions

For backend, deployment or backend test work, read and follow
[backend/AGENTS.md](backend/AGENTS.md), including its test selection and
infrastructure blocker rules. Backend Python commands run from `backend/`;
Docker Compose commands run from the repository root.

For frontend work, follow [frontend/AGENTS.md](frontend/AGENTS.md).
Project scope, architecture and contracts are defined in `docs/`.
